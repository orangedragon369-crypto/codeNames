# Code Names Operator Tile Generator

This program is a running website at -https://codenamestiles.web.app/

## what it does
- Builds a tile map of randomly placed color tile
- Takes user given, or preset values, to create the grid with any number of tiles in its width or length and create up to five color teams and any number of black tile
- All tile are given a check mark to help manage the board
- A button at the top giving a brief description of the rules of code names
- It stop and notifies if you ask it to put more tiles on the board than there is space
- Has word labels in case of color blind, black and white screen, bad monitor colors, etc.

## How To Run Locally

First run
```bash
git clone https://github.com/orangedragon369-crypto/codeNames
```
to clone locally.

Then from codeNames file
```
npm run dev
```
The script should give the url to go to to see it running. To quit local hosting close terminal or enter `q` to quit.
